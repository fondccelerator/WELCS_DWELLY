# Dwelly и WELCS — отчёт

Статический сайт из 12 страниц, без сборщика и зависимостей. Открывается локально двойным щелчком по `index.html`.

## Публикация на GitHub Pages
1. Создать репозиторий и положить в корень содержимое этой папки (`index.html`, остальные `.html`, папки `assets/` и `img/`, файл `.nojekyll`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

Отчёт собран по открытым источникам; гипотезы для WELCS — на странице «Рычаги». Репозиторий лучше сделать приватным, если отчёт не для публичного доступа.

## Устройство
- `index.html` — коротко по блокам; остальные страницы — разделы.
- `assets/style.css` — все стили (светлая и тёмная тема), `assets/app.js` — увеличение рисунков.
- `img/` — снимки: `NAME_s.webp` превью, `NAME.webp` крупно.
- Шрифты подгружаются с Google Fonts; без сети страница показывается системными шрифтами.

Правка текста — прямо в HTML-файле раздела, между `<main>` и `</main>`.
